Softwein.Secure Revision History
-------------------------------------------------------------------------------

1.0.2.0		2011-08-05
Initial release of Softwein.Secure.dll.

1.0.3.0		2011-10-04
Changed License.CreateKey from public to internal to protect against misuse.
Changed TripleDESCrypto class to internal to hide it in Object Browser.

1.1.0.0		2014-01-24
Changed License.key.

1.0.4.0		2014-03-04
1.1.4.0		2014-03-24	with new license key
Bug fix: License.GetNetworkAdapterAddress was returning both LAN and Bluetooth
    Ethernet adapter addresses. Now just looks for a LAN adapter.

1.1.5.0		2014-07-11
License.GetNetworkAdapterAddress() now looks for Ethernet adapters that either contain
"LAN" or "local area" in its name.

1.2.0.0		2015-01-14
Generate hardware fingerprint from disk ID or BIOS ID.

1.2.1.0		2015-01-28
Generate hardware fingerprint from motherboard ID or BIOS ID or logical disk ID.
Motherboard and BIOS will not change. Logical disk ID might be identical for identical PC's and
will change when reformatting disk.

1.3.0.0		2015-02-23
Extend licensing schema to include a dongle based license.

1.3.1.0		2015-04-09
Create a concatenated hardware fingerprint excluding whitespace and special characters to cover
cases where hardware ID's are short and contain special characters.
